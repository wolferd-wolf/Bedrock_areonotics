# Bedrock content pack

This directory contains the Bedrock Aeronautics behavior and resource packs.

Version 0.0.26 includes three original 64x64 project textures:

- `aeronautics_ship_core.png` — cyan-accented gunmetal core plating;
- `aeronautics_helm.png` — navy and amber instrument plating;
- `aeronautics_aero_engine.png` — graphite turbine casing with orange heat accents.

The block JSON binds these textures through `textures/terrain_texture.json`. The same material binding is used for placed blocks and inventory item visuals.

These assets are original to Bedrock Aeronautics. Do not add Mojang texture binaries, APK content, or extracted proprietary game assets to this repository.
